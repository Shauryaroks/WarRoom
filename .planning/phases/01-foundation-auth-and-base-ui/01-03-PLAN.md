**auth_utils.py** -- Create JWT utility module:

```python
import uuid
from datetime import datetime, timezone, timedelta
from typing import Optional

import jwt
from fastapi import Depends, HTTPException, status
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.database import get_db, settings
from app.models import Team, Admin

security = HTTPBearer()

def create_access_token(
    subject_id: uuid.UUID,
    role: str,  # "strategist", "trader", or "admin"
    team_id: Optional[uuid.UUID] = None,
) -> str:
    now = datetime.now(timezone.utc)
    payload = {
        "sub": str(subject_id),
        "role": role,
        "iat": now,
        "exp": now + timedelta(hours=settings.JWT_EXPIRY_HOURS),
    }
    if team_id is not None:
        payload["team_id"] = str(team_id)
    return jwt.encode(payload, settings.JWT_SECRET, algorithm=settings.JWT_ALGORITHM)

def decode_token(token: str) -> dict:
    try:
        return jwt.decode(token, settings.JWT_SECRET, algorithms=[settings.JWT_ALGORITHM])
    except jwt.ExpiredSignatureError:
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Token expired")
    except jwt.InvalidTokenError:
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Invalid token")

async def get_current_user(
    credentials: HTTPAuthorizationCredentials = Depends(security),
    db: AsyncSession = Depends(get_db),
) -> dict:
    """Returns dict with keys: id, role, team_id (None for admin), entity (Team or Admin object)."""
    payload = decode_token(credentials.credentials)
    role = payload.get("role")
    subject_id = payload.get("sub")

    if role == "admin":
        result = await db.execute(select(Admin).where(Admin.id == uuid.UUID(subject_id)))
        admin = result.scalar_one_or_none()
        if not admin:
            raise HTTPException(status_code=401, detail="Admin not found")
        return {"id": admin.id, "role": "admin", "team_id": None, "entity": admin}
    else:
        team_id = payload.get("team_id")
        if not team_id:
            raise HTTPException(status_code=401, detail="Invalid token: missing team_id")
        result = await db.execute(select(Team).where(Team.id == uuid.UUID(team_id)))
        team = result.scalar_one_or_none()
        if not team:
            raise HTTPException(status_code=401, detail="Team not found")
        return {"id": uuid.UUID(subject_id), "role": role, "team_id": team.id, "entity": team}

async def require_admin(
    current_user: dict = Depends(get_current_user),
) -> dict:
    if current_user["role"] != "admin":
        raise HTTPException(status_code=403, detail="Admin access required")
    return current_user

async def require_team(
    current_user: dict = Depends(get_current_user),
) -> dict:
    if current_user["role"] not in ("strategist", "trader"):
        raise HTTPException(status_code=403, detail="Team access required")
    return current_user
```

Endpoints:

   - Check ticker uniqueness (do NOT prepend "$" -- store raw ticker like "APEX")
   - Check email uniqueness across both strategist_email and trader_email of all teams
   - Hash password with bcrypt
   - Create Team with:
     - `strategist_email = request.email` (same email used for both -- user changes on first login if needed)
     - `strategist_password_hash = bcrypt.hashpw(request.password)`
     - `trader_email = request.email` (same email)
     - `trader_password_hash = bcrypt.hashpw(request.password)` (same password initially)
     - `status = TeamStatus.PENDING`

   - On duplicate email: 409 with detail "Email already registered"

   - Check team.status != PENDING (return 403 "Team not yet approved by admin" if pending)
   - Check team.status != REJECTED (return 403 "Team registration was rejected")
   - Create JWT with `subject_id=team.id`, `role=request.role`, `team_id=team.id`
   - Return token, team info, and role

3. `GET /api/v1/auth/me` -- Protected endpoint returning current user info:
   - Uses `get_current_user` dependency
   - Returns team_name, ticker, role, status

**api/admin.py** -- Admin authentication and team management. Per D-03, admin is a separate entity:

Router prefix: `/api/v1/admin`

Pydantic models:
- `AdminLoginRequest`: `email: EmailStr`, `password: str`
- `AdminLoginResponse`: `token: str`, `role: str` (always "admin")
- `TeamListItem`: `id: str`, `name: str`, `ticker: str`, `status: str`, `strategist_email: str`, `trader_email: str`, `created_at: str`
- `TeamActionResponse`: `message: str`, `team_id: str`, `new_status: str`

Endpoints:

1. `POST /api/v1/admin/login` -- Admin login:
   - Query `Admin` by email
   - Verify bcrypt password
   - Create JWT with `subject_id=admin.id`, `role="admin"`
   - Return token
   - On bad credentials: 401 "Invalid email or password"

2. `GET /api/v1/admin/teams` -- List all teams (requires admin):
   - Uses `require_admin` dependency
   - Optional query param `status` to filter (e.g., `?status=PENDING`)
   - Returns list of TeamListItem
   - Order by created_at desc

3. `POST /api/v1/admin/teams/{team_id}/approve` -- Approve a team (requires admin):
   - Uses `require_admin` dependency
   - Load team by id, verify status is PENDING
   - Set `team.status = TeamStatus.READY`
   - Set `team.approved_at = datetime.now(timezone.utc)`
   - Return 200 with new status
   - If team not found: 404
   - If team not PENDING: 409 "Team is not in pending status"

4. `POST /api/v1/admin/teams/{team_id}/reject` -- Reject a team (requires admin):
   - Uses `require_admin` dependency
   - Load team by id, verify status is PENDING
   - Set `team.status = TeamStatus.REJECTED`
   - Return 200 with new status

5. `POST /api/v1/admin/seed` -- Create initial admin account (no auth required, but only works if no admins exist):
   - Check if any Admin exists in DB
   - If yes: return 409 "Admin already exists"
   - If no: create admin with provided email/password
   - This is the bootstrap mechanism -- run once on first deploy

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> FastAPI | Untrusted input from browser; JWT validates identity |
| JWT token | Bearer token in Authorization header; signed with HS256 |
| Admin -> Team management | Elevated privilege; admin JWT required |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | JWT tokens | mitigate | HS256 with server-side secret; JWT_SECRET has no default (fails if unset); tokens expire after JWT_EXPIRY_HOURS |
| T-03-02 | Elevation of Privilege | Admin seed endpoint | mitigate | Only works when zero admins exist in DB; returns 409 after first admin created. Cannot be used to create additional admins. |
| T-03-03 | Information Disclosure | Password in JWT | mitigate | JWT payload contains only subject_id, role, team_id -- no passwords or sensitive data |
| T-03-04 | Tampering | Registration input | mitigate | Pydantic validation: ticker 3-5 uppercase alpha, email validated, password min 8 chars. bcrypt hashing for storage. |
| T-03-05 | Spoofing | CORS allow_origins=["*"] | accept | Competition app on controlled network. Frontend on Vercel, backend on VPS. Restrict origins in production deployment. |
| T-03-06 | Denial of Service | Registration endpoint | accept | No rate limiting in Phase 1. Acceptable for 40-team competition. Add rate limiting if needed. |
</threat_model>
