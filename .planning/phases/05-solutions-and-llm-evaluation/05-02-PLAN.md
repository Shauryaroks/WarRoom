```python
class SubmitSolutionRequest(BaseModel):
    content: str = Field(min_length=10, max_length=50000)
    solution_type: str = Field(pattern="^(INITIAL|MICROTWEAK)$")

class SolutionResponse(BaseModel):
    id: str
    content: str
    solution_type: str
    created_at: str
    evaluation_status: str | None  # from related evaluation

class CooldownResponse(BaseModel):
    cooldown_active: bool
    cooldown_until: str | None
    seconds_remaining: int

class CaselineResponse(BaseModel):
    caseline_document: str | None
    company_display_name: str | None
```

Endpoints:

1. `POST /submit` -- Submit a solution (per SOLN-01, SOLN-03)
   - Depends: require_team (only strategist role)
   - Validate role == "strategist" (raise 403 if trader)
   - Validate game is ACTIVE (get_game_state_readonly)
   - For INITIAL: validate elapsed_seconds < 3600 (1 hour window per D-02, SOLN-01)
   - For MICROTWEAK: validate team.cooldown_until is None or < utc_now() (per D-03, SOLN-03)
   - Create Solution record
   - For MICROTWEAK: set team.cooldown_until = utc_now() + timedelta(minutes=20) (per D-04, SOLN-04)
   - Dispatch Celery task: `evaluate_solution.delay(str(solution.id))`
   - Return SolutionResponse

2. `GET /my-solutions` -- Get team's solutions
   - Depends: require_team
   - Query Solution where team_id = current_user.team_id, ordered by created_at desc
   - Include evaluation status from related Evaluation
   - Return list[SolutionResponse]

3. `GET /cooldown` -- Get cooldown status (per SOLN-04)
   - Depends: require_team
   - Check team.cooldown_until: if None or past -> cooldown_active=False, if future -> cooldown_active=True with seconds_remaining
   - Return CooldownResponse

4. `GET /caseline` -- Get team's caseline document (per D-15)
   - Depends: require_team
   - Return CaselineResponse with team.caseline_document and team.company_display_name

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Elevation of Privilege | solutions.py /submit | mitigate | Check user.role == "strategist" before allowing submission. Trader gets 403. |
| T-05-06 | Tampering | solutions.py /submit | mitigate | Server-side elapsed_seconds check for 1-hour window (game timer is authoritative, not client clock). Cooldown check against Team.cooldown_until in DB. |
| T-05-07 | Tampering | solutions.py content | mitigate | Pydantic Field(max_length=50000) limits content size. Content stored as plain text, rendered via react-markdown (sanitizes HTML by default). |
| T-05-08 | Tampering | admin.py /evaluations/{id} PUT | mitigate | Only PENDING_APPROVAL evaluations can be edited. require_admin dependency enforces admin-only access. |
| T-05-09 | Tampering | admin.py /caseline | mitigate | Caseline assignment only allowed when game is in SETUP state. require_admin enforced. |
| T-05-10 | Denial of Service | solutions.py /submit | mitigate | 20-minute cooldown prevents rapid microtweak spam. Content max_length=50000 prevents oversized submissions. |
</threat_model>
