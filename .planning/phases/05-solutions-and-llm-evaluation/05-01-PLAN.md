**B) Create server/app/worker/tasks/evaluate_solution.py** following the game_tick.py pattern:

```python
import asyncio
import logging
from app.worker.celery_app import celery_app

logger = logging.getLogger(__name__)

@celery_app.task(
    name="solution.evaluate",
    time_limit=120,        # LLM calls can take 30-60s (override global 60s)
    soft_time_limit=100,
    max_retries=2,
    default_retry_delay=10,
)
def evaluate_solution(solution_id: str):
    """Evaluate a solution via OpenRouter LLM. Per EVAL-01."""
    asyncio.run(_evaluate(solution_id))

async def _evaluate(solution_id: str):
    from app.database import get_worker_session
    from app.services.evaluation_service import build_prompt, save_evaluation
    from app.services.llm_service import call_openrouter
    from app.redis_pubsub import publish_broadcast_sync, publish_to_team_sync
    import uuid

    async with get_worker_session() as db:
        try:
            prompt = await build_prompt(db, solution_id)
            llm_output, metadata = await call_openrouter(prompt)
            evaluation = await save_evaluation(db, solution_id, llm_output, metadata)
            await db.commit()

            # Notify admin after commit (per RESEARCH anti-patterns)
            publish_broadcast_sync({
                "type": "evaluation_pending",
                "payload": {
                    "evaluation_id": str(evaluation.id),
                    "team_id": str(evaluation.team_id),
                },
            })
        except Exception as e:
            logger.error(f"Evaluation failed for solution {solution_id}: {e}")
            # Mark evaluation as FAILED if it exists
            from app.models import Solution, Evaluation, EvaluationStatus
            from sqlalchemy import select
            result = await db.execute(
                select(Solution).where(Solution.id == uuid.UUID(solution_id))
            )
            solution = result.scalar_one_or_none()
            if solution:
                eval_obj = Evaluation(
                    solution_id=solution.id,
                    team_id=solution.team_id,
                    status=EvaluationStatus.FAILED,
                    raw_response=str(e),
                )
                db.add(eval_obj)
                await db.commit()

                publish_to_team_sync(solution.team_id, {
                    "type": "evaluation_failed",
                    "payload": {"solution_id": solution_id},
                })
            raise  # Let Celery retry
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Celery worker -> OpenRouter API | Untrusted external LLM response crosses into our system |
| LLM response -> Database | Unvalidated LLM output stored in evaluation records |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | llm_service.py | mitigate | Validate LLM response with json.loads + check required keys before saving. EVALUATION_SCHEMA enforces structure via OpenRouter. |
| T-05-02 | Information Disclosure | llm_service.py | mitigate | OPENROUTER_API_KEY loaded from env/settings, never logged. raw_response stored in DB for debug but only accessible to admin. |
| T-05-03 | Denial of Service | evaluate_solution.py | mitigate | time_limit=120 prevents runaway tasks. max_retries=2 prevents infinite retry loops. httpx timeout=90s prevents hanging connections. |
| T-05-04 | Tampering | evaluation_service.py | mitigate | approve_evaluation checks evaluation.status == PENDING_APPROVAL before processing. Prevents double-approval. |
</threat_model>
