**Endpoint 1: POST /teams/{team_id}/remove (per D-04)**
- Check game state via get_game_state_readonly(db)
- If SETUP: hard delete -- explicitly delete related records in order (Directive, StockHolding, Transaction where buyer/seller/target, CashLedger, PriceHistory) then delete team. Use `from sqlalchemy import delete` with `delete(Model).where(Model.team_id == team_id)` for each.
- If ACTIVE/PAUSED: soft remove -- set team.status = TeamStatus.BANKRUPT, team.bankrupt_since = datetime.now(timezone.utc)
- If FINISHED: raise 409 "Cannot remove teams from a finished game"
- Log ActivityEvent with event_type="TEAM_REMOVED", actor="admin", description including team name and remove type
- Broadcast via publish_broadcast: `{"type": "team_removed", "payload": {"team_id": str(team_id), "remove_type": "hard"|"soft"}}`

**Endpoint 2: POST /news/inject (per D-06, NEWS-01)**
- Create MarketNews record: headline=request.headline, content=request.body, source_type="ADMIN_INJECTED", affected_tickers=json.dumps(request.affected_tickers) if request.affected_tickers else None
- Log ActivityEvent: event_type="NEWS_INJECTED", description=f"News injected: {request.headline}"
- Broadcast: `{"type": "news_injected", "payload": {"id": str(news.id), "headline": news.headline, "content": news.content, "source_type": "ADMIN_INJECTED", "news_type": request.news_type, "affected_tickers": request.affected_tickers, "created_at": news.created_at.isoformat()}}`

**Endpoint 3: POST /broadcast (per D-05 -- broadcasts ARE news items)**
- Create MarketNews record: headline=request.message, content=None, source_type="ADMIN_BROADCAST"
- Log ActivityEvent: event_type="BROADCAST_SENT", description=f"Broadcast: {request.message[:80]}"
- Broadcast: `{"type": "news_injected", "payload": {"id": str(news.id), "headline": news.headline, "content": None, "source_type": "ADMIN_BROADCAST", "news_type": "GLOBAL", "affected_tickers": [], "created_at": news.created_at.isoformat()}}`
- Use same "news_injected" type so teams receive broadcasts in their news feed (per D-05)

**Endpoint 4: POST /game/advance-round**
- Get GameState, increment current_round by 1
- Log ActivityEvent: event_type="ROUND_ADVANCED", description=f"Advanced to Q{state.current_round}"
- Broadcast: `{"type": "round_advanced", "payload": {"current_round": state.current_round}}`

**Endpoint 5: GET /activity**
- Query ActivityEvent table, order by created_at desc, limit 200
- Return list[ActivityEventItem]

**Endpoint 6: GET /news/history**
- Query MarketNews table, order by created_at desc, limit 100
- Return list of news items with id, headline, content, source_type, affected_tickers (parsed from JSON), created_at

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Admin API | All admin endpoints receive untrusted input from the browser |
| Admin API -> Database | SQL queries constructed from user input |
| Admin API -> Redis pub/sub | Broadcast messages flow to all connected WebSocket clients |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege | All new endpoints | mitigate | Every endpoint uses `Depends(require_admin)` -- verified in tests |
| T-03-02 | Tampering | POST /news/inject | mitigate | Validate input via Pydantic NewsInjectRequest model; headline max length enforced by MarketNews.headline String(120) |
| T-03-03 | Tampering | POST /teams/{id}/remove | mitigate | Team ID is UUID path parameter validated by FastAPI; game state check is server-side |
| T-03-04 | Information Disclosure | GET /activity | accept | Activity log is admin-only (require_admin); no PII beyond team names |
| T-03-05 | Denial of Service | POST /broadcast | accept | Rate limiting deferred to production hardening; 80-user app with single admin |
| T-03-06 | Spoofing | Redis pub/sub broadcast | accept | Redis is internal network only (Docker); messages are server-originated |
</threat_model>
