1. In server/app/services/game_service.py, add set_game_phase function (per D-01, D-02):
```python
async def set_game_phase(db: AsyncSession, phase: str | None, macro_brief: str | None = None) -> GameState:
```
- Validate phase is one of "war_room", "live_floor", or None
- Get game state with FOR UPDATE lock
- Require game status == ACTIVE (raise ValueError otherwise)
- If phase == "war_room": set game_phase = "war_room", optionally set macro_brief if provided
- If phase == "live_floor": set game_phase = "live_floor", set current_quarter_start = now
- If phase is None: set game_phase = None (clear sub-state)
- Commit, refresh, update Redis cache (add game_phase to cached data)
- Broadcast via publish_broadcast with type="game_phase_changed", payload={game_phase, macro_brief, current_round}
- Return updated GameState

2. Add get_operating_budget function (per D-09):

```python
async def get_operating_budget(db: AsyncSession, team_id: uuid.UUID) -> dict:
```

- Load team with archetype eager-loaded
- If no archetype assigned, raise ValueError("Team has no archetype assigned")
- base_budget = archetype.starting_cash (this IS the budget base per D-09)
- For the multiplier: query the team's stock price performance vs archetype benchmark. For now, use a simple formula:
  - If current_round == 0: multiplier = 1.0
  - Else: look at team.stock_price vs archetype.starting_stock_price ratio, clamp multiplier to [0.7, 1.3]
  - multiplier = max(0.7, min(1.3, stock_price / starting_stock_price))
- budget = base_budget \* Decimal(str(multiplier))
- Query total budget_spent from Decision table for this team + current round
- Return {"total_budget": str(budget), "allocated": str(total_spent), "remaining": str(budget - total_spent), "multiplier": multiplier}
