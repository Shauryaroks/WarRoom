**Endpoints:**

1. `GET /api/v1/admin/archetypes` -- List all archetypes. Returns `list[ArchetypeResponse]`. Requires admin.

2. `POST /api/v1/admin/archetypes` -- Create a custom archetype (per D-07). Validate benchmark_bands is valid JSON with keys market_share, margin, growth, ops_efficiency (each a 2-element array). Set `is_preset=False`. Returns `ArchetypeResponse`, 201. Requires admin. Reject duplicate slug with 409.

3. `GET /api/v1/admin/archetypes/{archetype_id}` -- Get single archetype. Returns `ArchetypeResponse`. Requires admin.

4. `PUT /api/v1/admin/archetypes/{archetype_id}` -- Update archetype. Accept same fields as create (all optional except via partial update). Reject updating preset archetypes' slug. Requires admin.

5. `DELETE /api/v1/admin/archetypes/{archetype_id}` -- Delete archetype. Prevent deletion if any teams are assigned. Prevent deletion of preset archetypes. Requires admin.

6. `POST /api/v1/admin/teams/{team_id}/assign-archetype` -- Assign archetype to team (per D-02, D-06, D-08).
   - Accept `ArchetypeAssignRequest` body with archetype_id
   - GUARD: Only allowed when game is in SETUP status (per D-08). Return 409 otherwise.
   - Load the archetype, then update team:
     - `team.archetype_id = archetype.id`
     - `team.caseline_document = archetype.dossier_content`
     - `team.company_display_name = archetype.name`
     - `team.cash = archetype.starting_cash`
     - `team.stock_price = archetype.starting_stock_price`
     - `team.shares_outstanding = archetype.starting_shares`
     - `team.swot_strengths = archetype.swot_strengths`
     - `team.swot_weaknesses = archetype.swot_weaknesses`
     - `team.swot_opportunities = archetype.swot_opportunities`
     - `team.swot_threats = archetype.swot_threats`
   - Log ActivityEvent "ARCHETYPE_ASSIGNED"
   - Return `ArchetypeAssignResponse`
