       - Currently: 80px sidebar + 320px content panel + flex-1 chart = needs 400px+ minimum for chart.

       - Verify header elements don't overflow.
       - At md: Reduce horizontal padding. Truncate team name if too long.
       - Timer and status indicators must remain visible at all widths.

    4. **CompanyTabs overflow:**
       - With 32-40 teams, tabs may overflow. Add horizontal scroll with overflow-x-auto and hide scrollbar (scrollbar-hide utility).
       - Ensure the selected tab scrolls into view.

    5. **Chart container:**
       - CandlestickChart uses a ResizeObserver (or similar) -- verify it responds to container size changes.
       - Add min-w-0 to prevent flex overflow (already present -- verify).

       - Add scrollbar-hide utility if not present:
         ```css
         .scrollbar-hide::-webkit-scrollbar { display: none; }
         .scrollbar-hide { -ms-overflow-style: none; scrollbar-width: none; }
         ```

    **Do NOT add mobile-first responsive design** -- the app targets laptop/desktop screens per the constraints (teams are co-located with laptops). Just ensure no breakage below 1280px and graceful degradation at 768px.
