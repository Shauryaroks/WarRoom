1. `async def preview_trade(db: AsyncSession, buyer_team_id: UUID, target_team_id: UUID, shares: int, trade_type: str) -> dict`:
   - No locks needed (read-only preview per D-06)
   - Return: {target_ticker, shares, price_per_share (str), total_cost (str), available_cash (str), shares_available (int remaining before 30% cap), current_holding (int)}
   - Validate buyer_team_id != target_team_id (T-04-05)
   - Validate shares > 0

2. `async def execute_buy(db: AsyncSession, buyer_team_id: UUID, target_team_id: UUID, shares: int) -> Transaction`:
   Per D-08, all within a single transaction:
   a. Validate buyer_team_id != target_team_id
   b. `SELECT FOR UPDATE` on target Team row -> get stock_price, public_float
   c. `SELECT FOR UPDATE` on ALL StockHolding rows where target_team_id matches -> sum total_external
   d. Check: total_external + shares <= int(public_float * 0.30). Raise ValueError if exceeded.
   e. `SELECT FOR UPDATE` on buyer Team row -> check cash >= stock_price * shares. Raise ValueError if insufficient.
   f. Deduct cash from buyer: buyer.cash -= total_cost
   g. Create or update StockHolding (owner=buyer, target=target): increment shares_owned, add to total_cost_basis
   h. Create Transaction row (type=BUY, buyer=buyer, target=target, shares, price_per_share=stock_price, total_value)
   i. Create CashLedger entry (team=buyer, entry_type="TRADE_BUY", amount=-total_cost, balance_after=buyer.cash)
   j. Do NOT commit -- caller commits. Do NOT publish Redis messages inside the transaction (per RESEARCH anti-patterns).
   k. Return the Transaction object

3. `async def execute_sell(db: AsyncSession, seller_team_id: UUID, target_team_id: UUID, shares: int) -> Transaction`:
   a. Validate seller_team_id != target_team_id
   b. `SELECT FOR UPDATE` on target Team -> get stock_price
   c. `SELECT FOR UPDATE` on StockHolding (owner=seller, target=target) -> check shares_owned >= shares
   d. Calculate proceeds = stock_price * shares
   e. Update StockHolding: shares_owned -= shares, adjust total_cost_basis proportionally (cost_basis * (remaining/original))
   f. If shares_owned becomes 0, delete the StockHolding row
   g. Add cash to seller: seller.cash += proceeds (SELECT FOR UPDATE on seller Team first)
   h. Create Transaction (type=SELL, seller=seller, target=target)
   i. Create CashLedger (entry_type="TRADE_SELL", amount=+proceeds, balance_after=seller.cash)

4. `async def get_portfolio(db: AsyncSession, team_id: UUID) -> dict`:
   - Query all StockHoldings where owner_team_id = team_id with eagerly loaded target_team (for ticker, stock_price)
   - For each holding: compute P&L = (current_price * shares_owned) - total_cost_basis, pct_change
   - Get team's cash balance
   - Return: {cash (str), holdings: [{target_team_id, ticker, shares_owned, avg_buy_price (str), current_price (str), market_value (str), pnl (str), pnl_pct (str), ownership_pct (str)}], total_holdings_value (str), net_worth (str = cash + holdings_value)}

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Trading API | Untrusted trade requests from authenticated team users |
| Trading API -> PostgreSQL | Atomic transaction with row-level locking |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Tampering | execute_buy | mitigate | Validate buyer_team_id != target_team_id (self-trade prevention) |
| T-04-06 | Elevation of Privilege | POST /buy, /sell | mitigate | Check current_user["role"] == "trader", raise 403 for strategist |
| T-04-07 | Tampering | TradeRequest.shares | mitigate | Pydantic Field(gt=0) prevents zero/negative share trades |
| T-04-08 | Tampering | 30% cap bypass | mitigate | SELECT FOR UPDATE on ALL StockHolding rows for target, serialized lock acquisition |
| T-04-09 | Tampering | Insufficient cash bypass | mitigate | SELECT FOR UPDATE on buyer Team row, check cash >= total_cost within locked transaction |
| T-04-10 | Information Disclosure | GET /portfolio | accept | Team can only view own portfolio (team_id from JWT, not request body) |
| T-04-11 | Denial of Service | Trade spam | accept | Low risk for 40-team competition; add rate limiting in Phase 6 if needed |
