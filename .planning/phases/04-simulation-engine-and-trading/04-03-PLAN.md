1. **Create client/src/stores/market-store.ts** -- Zustand store for market data (NO persist -- ephemeral game data):

```typescript
interface MarketState {
  // Company list
  companies: CompanyInfo[];
  selectedCompanyId: string | null;

  // Raw price ticks per company (for candle aggregation)
  priceTicks: Record<string, Array<{ price: number; timestamp: number }>>;

  // Aggregated 5-min candles per company
  candles: Record<string, CandleData[]>;

  // Current prices (latest from WebSocket)
  currentPrices: Record<string, { price: string; change_pct: string; market_cap: string }>;

  // Actions
  setCompanies: (companies: CompanyInfo[]) => void;
  selectCompany: (teamId: string) => void;
  handlePriceUpdate: (prices: PriceTickData[]) => void;
  loadPriceHistory: (teamId: string, history: PriceHistoryPoint[]) => void;
  reset: () => void;
}
```

Key implementation details:
- `handlePriceUpdate`: For each price in the update, append to priceTicks[teamId], update currentPrices[teamId], then re-aggregate candles for that team using 5-minute buckets (per D-10 and RESEARCH Pattern 4).
- `aggregateToCandles` function: Group ticks into 300-second (5-min) buckets. Each bucket: time = bucket start (unix), open = first tick price, high = max, low = min, close = last tick price.
- `loadPriceHistory`: Convert PriceHistoryPoint[] (from REST backfill) to priceTicks format and aggregate. Use this on initial load and reconnect per RESEARCH Pitfall 4.
- `selectCompany`: Set selectedCompanyId. If no ticks exist for that company, trigger a fetch (component responsibility, not store).
