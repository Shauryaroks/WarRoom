Implementation rules:
1. Use `useRef` for containerRef (HTMLDivElement), chartRef (IChartApi), seriesRef (ISeriesApi<"Candlestick">)
2. Create chart ONCE in `useEffect([], ...)` with `createChart(containerRef.current, options)`:
   - Layout: background `#0e0e0e` (surface-lowest), textColor `#89919d` (muted-foreground)
   - Grid: vertLines/horzLines at `rgba(33,150,243,0.03)` (primary-tinted per DESIGN.md)
   - Crosshair mode: 0 (Normal)
   - TimeScale: borderColor `#2a2a2a`, timeVisible: true, secondsVisible: false
   - RightPriceScale: borderColor `#2a2a2a`
3. Add series via `chart.addSeries(CandlestickSeries, options)` (v5 API, NOT `addCandlestickSeries`):
   - upColor: `#40e56c` (success), downColor: `#FF1744` (destructive)
   - wickUpColor: `#40e56c`, wickDownColor: `#FF1744`
   - borderVisible: false
4. ResizeObserver on containerRef -- call `chart.applyOptions({ width, height })` on resize
5. Cleanup: `chart.remove()` and `observer.disconnect()` in useEffect return (per RESEARCH Pitfall 3)

Data update strategy (critical for performance):
- When `data` prop changes and has items:
  - If data length increased by 1 (new candle or updated last candle): use `seriesRef.current.update(lastCandle)` -- O(1)
  - If data changed significantly (company switch, backfill): use `seriesRef.current.setData(data)` followed by `chartRef.current.timeScale().fitContent()`
- Track previous data length in a ref to detect the change type

Container: `<div ref={containerRef} className={cn("w-full h-full min-h-[300px]", className)} />`. No border radius (0px per DESIGN.md).
