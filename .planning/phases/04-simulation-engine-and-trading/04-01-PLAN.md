| Admin API -> simulation_service | Admin-only endpoint modifies team target_price |
| Celery worker -> PostgreSQL | Worker writes PriceHistory, updates Team.stock_price |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Elevation of Privilege | POST /set-score | mitigate | `Depends(require_admin)` enforces admin-only access |
| T-04-02 | Tampering | SetScoreRequest | mitigate | Pydantic `Field(ge=0.0, le=1.0)` validates score range |
| T-04-03 | Information Disclosure | price_update broadcast | accept | All prices are public game info -- broadcast to all clients is intended |
| T-04-04 | Denial of Service | game_tick frequency | accept | Celery Beat runs every 60s with game-active guard, bounded workload |
