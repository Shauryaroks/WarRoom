<interfaces>
From 09-05 — backend endpoints this plan consumes:
- GET  /api/v1/admin/fundamentals-queue?status=PENDING_APPROVAL -> list[FundamentalEvalListItem]
- PATCH /api/v1/admin/fundamentals-queue/{id} -> FundamentalActionResponse
- POST /api/v1/admin/fundamentals-queue/{id}/approve -> FundamentalActionResponse
- POST /api/v1/admin/fundamentals-queue/{id}/reject -> FundamentalActionResponse (body {admin_notes?})
- POST /api/v1/admin/teams/{id}/override-fundamentals -> FundamentalActionResponse (body FundamentalOverrideRequest)
- GET  /api/v1/admin/teams/{id}/fundamentals -> TeamFundamentalsResponse
- GET  /api/v1/teams/me/fundamentals -> TeamFundamentalsResponse

WS message types emitted by backend:

- fundamental_evaluation_pending {evaluation_id, team_id, round_number}
- fundamentals_updated {team_id, ticker, fundamentals, drift_target_pct, drift_floor_pct}
- fundamentals_rejected {team_id, evaluation_id}
- fundamental_evaluation_failed {team_id, round_number} (team-scoped channel)
- shock_applied {shocks: [{team_id, ticker, magnitude_pct, source, direction}]}

TypeScript TeamFundamentalsResponse shape:

```
{
  team_id: string;
  ticker: string;
  fundamentals: { market_share: string|null; margin: string|null; growth: string|null; ops_efficiency: string|null };
  bands: Record<"market_share"|"margin"|"growth"|"ops_efficiency", [number, number]>;
  z_scores: { z_market_share: string; z_margin: string; z_growth: string; z_ops_efficiency: string };
  weighted_z: string;
  drift_target_pct: string | null;
  drift_floor_pct: string | null;
  ramp_started_at: string | null;
  ramp_fraction: string;
}
```
